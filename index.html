How ToonForge works

Enter a story, generate scenes, then preview or play the full sequence. The studio builds simple 3D cartoon scenes in your browser and can use your device's speech voices.

Export: The Export video button records the animated canvas as a WebM video. Browser voice narration is played separately and may not be included in the recording on every device.

Important: This starter version creates procedural 3D cartoon scenes; it is not a cloud AI text-to-video service. A hosted AI video API would require an API key and backend server, which GitHub Pages alone cannot securely provide.
